# EcoRastreadores

**EcoRastreadores** es una aplicación educativa Android dirigida a niños de 8 a 12 años, que funciona como un simulador interactivo de monitoreo ambiental.

## Funcionalidades Principales
- **Centro de Comando:** Visualiza en un mapa interactivo el nivel de contaminación de las diferentes zonas.
- **Laboratorio Móvil:** Realiza experimentos reales (pH de agua, filtrado de aire y análisis de ruido acústico) para solucionar emergencias ambientales.
- **Bitácora:** Colecciona insignias y reportes al salvar cada ecosistema.
- **100% Offline:** Arquitectura basada en SQLite (Room), sin necesidad de internet.

## Estructura del Proyecto
- `app/`: Contiene el código fuente Android (Kotlin, Jetpack Compose).
- `docs/`: Documentación del proyecto (Manuales de Usuario y Técnico).
- `.github/workflows/`: Pipelines de CI/CD para generar el APK mediante GitHub Actions.
